# Кентовка

Голос, чат, стримы и файлы для своей компании — без чужих серверов.

- `server.js`, `public/` — сервер и страница (голос, чат, файлы).
- `app/` — приложение для Windows (Electron): друзья, личка, группы, аккаунт, мосты.
- `bridge/` — мост для своего VPS (`install.sh`).
- `android/` — приложение для Android. Собирается на GitHub: вкладка **Actions** → **Android APK** → **Run workflow**, готовый APK — в разделе «Artifacts».
